# Test books

Public-domain EPUBs from Project Gutenberg, unchanged (each carries Project Gutenberg's own
licence section at its end, which the reader treats as back matter, not as the end of the book).

| File | Book | Source | Why |
|---|---|---|---|
| `peter-rabbit.epub` (1.5 MB) | Beatrix Potter, *The Tale of Peter Rabbit* (1902) | Project Gutenberg #14838, EPUB 3 with images | 29 pictures; short, so its end (Finish) is a few pages away |
| `metamorphosis.epub` (0.3 MB) | Franz Kafka, *Metamorphosis*, tr. David Wyllie | Project Gutenberg #5200, EPUB 3 | Plain text in three chapters |

The `.jpg` files are each book's own cover image, taken out of the EPUB, so the stand-in book page
can show the cover before the reader (and its engine) has loaded.
