# book-tracker (working title)

A book tracker built web first: a mobile website, installable as a PWA, polished and shipped first.
Native Swift and Kotlin apps only later, ported from the web app when it is worth it.

Core loop for v1: search a book → **Want to read** → **Currently reading** (start date) → **Finished**
(end date + rating). Custom shelves as a nice-to-have.

Setup, spec and design follow; see the issues once they exist.
