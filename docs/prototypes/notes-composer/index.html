The Notes and buddy-read composer: three versions

Static mock-ups on the app's real tokens, for docs/plans/notes-composer.md. Each phone below is live: tap the field and a faux 291 px keyboard comes up, tap Done or drag the thread and it goes. Open a version in its own page for every switch (reply, Everyone, big text, finger targets, today's bug).

Today, fixed keeps the layout and fixes the bugs and the sizes. In the capsule moves scope and Spoiler inside the field's capsule. Send as puts the audience on the send button. All three keep Friends as the default and show a note's audience before it is sent.
