Three rows under the bar

Each file is the card with the order you asked for: cover, title, author, the progress line, then one row with 42 %, 126 of 300 and the action at the right edge. No dot, no “p.”, no pace line. Every file carries the same seven states (A mid-read, B percent only, C 0 %, D “The end.”, E +24, F German at 360 px, L the Library tab) in both themes.

The three differ in one decision only: what happens when the row cannot hold the German word. At 360 px the row is 202 px wide, the numbers take 124–138 px and “Aktualisieren” alone takes 104 px. Something has to give, and each file gives something different.

Option C

One row at every width — the action becomes an icon

The only one that keeps your row and the 151 px card in both languages: the action gives up its word for a pencil (a check at the end, an arrow for Undo), which frees the 104 px the German label needed.
