# Libellus — Motion Language

**Not written yet.** The motion vocabulary is decided with the visual direction in the design round
(#4/#5) and written here then, the way Trappist's `docs/MOTION.md` was: a few laws, the token table,
the named motions (press, push, sheet, crossfade…), haptics, Reduce Motion, explicit non-motions.

Until then the only durations are the placeholder `duration` tokens in `design/tokens.json`
(`quick`, `standard`, `exit`), exposed as `--duration-*`. No other duration is written anywhere, and
everything honours `prefers-reduced-motion`.
