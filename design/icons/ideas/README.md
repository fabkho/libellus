# Home-screen icon ideas (#83)

Design exploration for the Android home-screen icon; nothing here ships. The review page with all
five ideas (themed and full colour, launcher masks, favicons, legibility notes) is generated by
`build.mjs`.

| Idea | Mark |
|---|---|
| `01-li-lit` | Today's “li”, redrawn in Newsreader ExtraBold italic as large as the safe zone allows; the i's dot is the lamp. |
| `02-open-book` | An open book from the front with the lamp over its spine: together a lower-case i. |
| `03-under-the-lamp` | A lamp shade and its cone of light, an open book where the light lands. |
| `04-two-ribbons` | “li” as two slanted bookmark ribbons on cloth red, the lamp as the dot. |
| `05-reading-room` | A lit arched window with a Newsreader italic L standing in it. |

Each folder holds:

- `icon.svg`: the full-colour adaptive icon on the 108 dp canvas (Chrome's maskable icon). The mark
  is placed by code inside the 66 dp safe zone, so no launcher mask cuts it.
- `monochrome.svg`: the same mark as one alpha shape, for the manifest's `purpose: "monochrome"`.
  The launcher tints it for themed icons.
- `favicon.svg`: the full-bleed rounded square with the mark enlarged for 32 and 16 px.

All three are plain paths: Newsreader is converted to outlines, so no font is needed at runtime.

## Rebuild

```sh
mkdir -p /tmp/icon-tools && (cd /tmp/icon-tools && npm init -y && npm i opentype.js wawoff2)
(cd web && pnpm install)   # or set FONTSOURCE_DIR to another node_modules/@fontsource
ICON_TOOLS=/tmp/icon-tools node design/icons/ideas/build.mjs /tmp/libellus-icons/index.html
```

Colours come from `design/tokens.json`. opentype.js and wawoff2 are deliberately not dependencies of
the repo; the build ticket for the chosen icon decides how the production pipeline
(`web/scripts/render-icons.mjs`) draws it.
